04

Connect Supabase and SendGrid

The generated local env files contain placeholders only. Replace them before starting the app or deploying the function.

1

Set browser-safe Supabase values

Edit .env.local in the generated app.

.env.local 
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
2

Link and migrate the database

Create a hosted Supabase project, then apply the checked-in contacts migration.

supabase link --project-ref <project-ref>
supabase db push
3

Set private Edge Function secrets

Verify the sender identity in SendGrid, then edit supabase/functions/.env.local.

supabase/functions/.env.local 
SENDGRID_API_KEY=SG.your-api-key
SENDGRID_FROM_EMAIL=verified-sender@example.com
SENDGRID_TO_EMAIL=inbox@example.com
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
4

Upload and deploy

supabase secrets set --env-file supabase/functions/.env.local
supabase functions deploy send-contact-email --no-verify-jwt
Keep private

Never prefix the service-role key or SendGrid API key with VITE_. Vite exposes those variables to browser code.

05

Run and verify

Complete this short checklist before treating the generated project as ready for feature work.

bun run check
bun dev
06

Troubleshooting

Most setup failures happen before application code runs. Start with the message printed by the creator.

Target is not empty

Choose a nonexistent folder or remove the contents of the intended target. The creator never overwrites an existing project.

Supabase CLI missing

Install it before local development or deployment commands. It is not needed for the initial hosted frontend scaffold.

Docker daemon stopped

Start Docker Desktop or your Docker service before using --local-supabase or supabase start.

Supabase env error

Confirm .env.local exists and both VITE_SUPABASE_* values are real project credentials.

SendGrid 401 or 403

Check the API key permission and confirm SENDGRID_FROM_EMAIL belongs to a verified identity.

Public function abuse

Add rate limiting or Turnstile before production because anonymous contact submission is intentionally enabled.
