04

Connect Supabase and SendGrid

The generated env files contain placeholders only. Replace them before starting the app or deploying the function.

1

Set browser-safe Supabase values

Edit .env.local.

.env.local
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
2

Link and migrate the database

Create a hosted Supabase project, then apply the checked-in migration.

supabase link --project-ref <project-ref>
supabase db push
3

Set private function secrets

Verify the sender identity in SendGrid, then edit supabase/functions/.env.local.

supabase/functions/.env.local
SENDGRID_API_KEY=SG.your-api-key
SENDGRID_FROM_EMAIL=verified-sender@example.com
SENDGRID_TO_EMAIL=inbox@example.com
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
4

Upload and deploy

supabase secrets set --env-file supabase/functions/.env.local
supabase functions deploy send-contact-email --no-verify-jwt
Keep private

Never prefix the service-role key or SendGrid API key with VITE_. Vite exposes those variables to browser code.

06

Troubleshooting

Most setup failures happen before application code runs. Start with the message printed by the creator.

Target is not empty

Choose a nonexistent folder or empty the target. The creator never overwrites a project.

Supabase CLI missing

Install it for local development or deployment. It is not needed for the initial hosted scaffold.

Docker daemon stopped

Start Docker before using --local-supabase or supabase start.

Supabase env error

Confirm .env.local exists and both public credentials are real.

SendGrid 401 or 403

Check API key permission and verify the configured sender identity.

Public function abuse

Add rate limiting or Turnstile before production because anonymous submission is enabled.
